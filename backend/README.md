# WyvernForge Backend

NestJS API — серверная часть платформы.

## Стек
- NestJS + TypeScript
- Prisma ORM
- PostgreSQL
- Redis
- Socket.io (будет добавлен)

## Запуск (после полной инициализации)

```bash
cd backend
npm install
npx prisma generate
npm run start:dev
```

API будет доступен на http://localhost:3001
