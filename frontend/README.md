# WyvernForge Frontend

Next.js 15 приложение — клиентская часть платформы.

## Стек
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS (будет добавлен)
- TanStack Query
- Socket.io-client

## Запуск (после полной инициализации)

```bash
cd frontend
npm install
npm run dev
```

Откроется на http://localhost:3000
